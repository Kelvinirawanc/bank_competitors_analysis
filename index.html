Methodology

How the analysis works

1

Discover or load target app IDs by keyword, then validate the match before collection.

2

Collect written reviews and ratings from Google Play (Indonesia) using multiple languages and sort orders.

3

Deduplicate by review ID and retain date, app version, helpful votes and developer replies.

4

Apply deterministic sentiment, topic and issue classification as a transparent baseline.

5

Use the resulting dataset for trend, pain-point and cross-industry comparison.

Important: collected written reviews are not the same as the total number of store ratings. The Google Play review endpoint can have coverage limits, so this dashboard is designed as a comparative sample rather than a census.
